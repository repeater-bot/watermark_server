# Watermark Server

</div>

## 简介

这是一个基于 `traceless-watermark` 的水印服务
支持将不可见水印添加到图片中
全程在内存中执行，不涉及文件读写。


## 部署

```shell
git clone https://github.com/repeater-bot/watermark_server.git
cd watermark_server
poetry install
```

## 使用

```shell
poetry run watermark_server.py
```
